§ What's locked

Cats are cosmetic collectibles layered on top of a functional Class system — the class carries the gameplay identity, the cat skin carries the look.

  • ✓ Cats affect PvP — through the class they belong to (see below). Not purely cosmetic after all.
  • ✓ Cat Classes: 3-4 classes exist. Each class grants a unique special ability and a class-flavored starter battle deck — still exactly 10 Attack + 10 Guard cards (Section 06's count stays fixed), just with different printed values/effects per class.
  • ✓ Cats vs. Classes: a "cat" is a cosmetic skin; a "class" is the functional gameplay category. Proposed (not yet explicitly confirmed): multiple cosmetic cat skins can share the same underlying class — flag if that's not the intent.
  • ✓ Unlock system: both purchasable (Booster Packs / Gems, Section 16) and earned through Campaign mode play (Section 22).
  • ✓ Starting/Maximum HP: Base 100, from equipment only (Section 04) — unaffected by class or cat choice.
  • ✓ Starting stats: HP 100, Attack/Defense start at 0 bonus (equipment resets to Level 1 every match).
  • ✓ Class-specific ability names, exact deck value differences, and cat skin roster are all deferred to asset creation — same treatment as equipment level magnitudes and combat card values.

§ Resolved decisions

  • Are cats purely cosmetic? No — classes carry gameplay function; the individual cat skin is cosmetic.
  • Does each cat have a unique ability? The class has a unique ability, shared by any cat skins within that class.
  • Starting HP: 100 (Section 04).
  • Maximum HP: 100 + equipment bonuses, no cat/class modifier.
  • Starting stats: HP 100, Attack/Defense 0 bonus at match start.
  • Character classes/archetypes: Yes — 3-4 classes, each with a unique ability and flavored starter deck.
  • Unlock system: Both purchasable and earned through Campaign play.
  • Whether characters affect PvP: Yes, via class ability and deck flavor.

§ Open questions

  • Movement characteristics: Fully uniform — all cats/classes move identically per Section 02's path-following rule. No class-based movement variation.
  • Cosmetic customization — accessories/skins layered on top of a base cat model?
