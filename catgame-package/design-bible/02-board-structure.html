2. Board Structure

All questions resolved — path network, properties, and special locations fully defined

§ What's locked

Revised from an open 2D grid to a single-tile-wide path network woven through a fixed 20x20 grid — properties, Town Center, and special locations are fixed points connected by procedurally-generated walkways.

  • ✓ There is a 2D board: a fixed 20x20 grid (400 tiles). Topology revised — no longer a fully open grid; movement is now constrained to a single-tile-wide path network (see below), closer to a branching track than free 2D movement.
  • ✓ The outermost ring of tiles is a permanent path — always walkable, can never hold a property or be built on. This also defines the board's hard boundary; there's no wrap-around.
  • ✓ Town Center: a walled 5x5 block at the exact center of the grid, where all players start. It's impassable from any side except 4 middle exit tiles (one per edge of the 5x5 block) — same "impassable block, limited entry point" logic as properties, just bigger. Each exit connects into the procedural path network.
  • ✓ Path/obstacle system: any blank space wider than 1 tile gets filled with obstacles (trees, crates, etc.) so that all walkable space forms a continuous single-tile-wide path — no open 2D areas remain. This guarantees a clear visual route between every point of interest.
  • ✓ Movement is now path-following (track-style), not free straight-line-in-any-direction. A roll moves the player that many tiles along the path. At forks, the player actively chooses which branch to take — confirmed, and intentional: this creates a real chasing dynamic, where a player can deliberately steer toward another player's position to pursue them across the board, rather than movement being purely random or fixed.
  • ✓ Generation order revised: properties are placed first (as before, at game setup), then the obstacle/path layout is procedurally generated around them each game — this is a partial procedural-generation step, not a fully procedural board. The 20x20 grid, Town Center, and outer ring stay fixed; only the tree/crate obstacle placement varies per game.
  • ✓ Properties can be placed on blank interior tiles (anywhere that isn't the outer path ring or the Town Center).
  • ✓ A property occupies a 3x3 block + 1 entry tile (10 tiles total). The entry tile sits directly above the block's center tile and is the only tile that counts as a "visit." The 3x3 block itself is impassable — players must route around it via the path network.
  • ✓ Property spacing: two property blocks must be placed at least 1 tile apart — no two properties can sit directly adjacent (locked in Section 09). This spacing is what the path/obstacle system fills in.
  • ✓ Each player can own and place a maximum of 2 properties, decided at the start of each game. With a 5-player max, that's up to 10 properties possible on one board.
  • ✓ Dungeons are cut entirely from scope (formerly Section 13) — no dungeon spaces exist on the board.
  • ✓ Plain board tiles ("normal locations") have no special effect — just walkable ground.
  • ✓ Three new special-purpose tile types exist, distinct from player-owned properties: an Inn, a Blacksmith, and a Church — one of each, randomly placed among blank spaces at game start to aid players. The path network must connect to each of these too.
  • ✓ Church's function: purification — removes Poison and Paralysis status effects (see Section 04/12 for what these do and where they come from).
  • ✓ Inn, Blacksmith, and Church all cost Coins to use (locked in Section 10) — exact amounts deferred to a balance pass. The Fountain (Campaign-exclusive, Section 22) stays free since it grants rewards rather than providing a paid service.
  • ✓ Inn/Blacksmith/Church footprint: 2x2 block + 1 entry tile — smaller than a property's 3x3 footprint, but same "block + single interactive entry tile" pattern.
  • ✓ No shortcuts or portals exist on the board — movement is entirely path-based, no teleportation.
Amendment — unification pass 2026-08-28 Two 1×1 board hazard tiles were promoted to canon from the prototype (authoritative detail in MASTER-DATA-SHEET.md §3 / §5): Poison Swamp (triggers on every tile of movement through it, applies the Poisoned status) and Thorn Vines (triggers on pass-through, applies Snared — the next roll is coin-flip-gated: even → roll normally, odd → move exactly 1 tile; then it clears). Snared is deliberately distinct from Paralysis. Placeholder density is 3 of each per board; final counts are a balance-pass number.
Ripple effect worth watching The Section 01 proximity check (distance 0–1, 8-directional) still works mechanically, but will trigger less often now — most of the 8 surrounding tiles around any given path tile will typically be obstacles, not open ground. This isn't a contradiction, just a natural consequence: PvP/alliance encounters will now cluster more tightly along the path network itself.

§ Resolved decisions

  • Board dimensions / layout: Fixed 20x20 grid, single-tile-wide path network (revised from open grid).
  • Number of spaces: 400 tiles total — outer permanent path ring, walled 5x5 Town Center, blank interior tiles (now split between path tiles and obstacle tiles), up to 10 properties (10 tiles each), plus the Inn/Blacksmith/Church.
  • Types of spaces: Permanent path, Town Center, path tile, obstacle tile (trees/crates), property (block + entry tile), and special-purpose tiles (Inn/Blacksmith/Church).
  • Starting area: Town Center — a walled 5x5 block at the board's center, exited via 4 middle tiles (one per edge), each connecting into the path network.
  • Movement direction: Path-following (revised from free straight-line movement) — the player moves along the single-tile path for the rolled distance, choosing a branch at forks.
  • Fixed or procedural: Revised — the grid/Town Center/outer ring are fixed, property placement is chosen each game, and the obstacle/path layout filling the gaps is procedurally generated after properties are placed.
  • Blank property spaces: Any interior tile that isn't the outer path ring or the Town Center.
  • Dungeon spaces: N/A — dungeons cut entirely from scope.
  • Normal locations: Plain walkable tiles, no effect.
  • Special locations: Inn, Blacksmith, Church — one of each, randomly placed at game start. Functions locked (heal/level/cure); footprint size still open.
  • Board boundaries: Hard edges at the 20x20 limit — no wrap-around.
  • Whether properties can block movement: Yes — the 3x3 block is impassable.
  • Whether properties occupy one or multiple tiles: Multiple — 3x3 block + 1 entry tile (10 total).
  • Maximum properties on one board: Up to 10 (2 per player × max 5 players).
  • Whether players can place properties before the game starts: Yes — placement happens at game setup.
  • Whether property placement can affect strategic routes: Yes — impassable blocks force players to route around them.

§ Special locations — resolved decisions

  • Footprint size of the Inn, Blacksmith, and Church: 2x2 block + 1 entry tile (smaller than the 3x3 property footprint).
  • What each of the Inn, Blacksmith, and Church does: Inn heals HP, Blacksmith levels equipment, Church cures Poison/Paralysis. Exact Inn healing amount still TBD.
  • Shortcuts/portals: No — the board stays limited to path tiles, obstacles, properties, and the three special locations. No teleport-style mechanics.
