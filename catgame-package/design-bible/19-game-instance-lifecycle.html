19. Game Instance Lifecycle

All questions resolved
Checkbox clicks won’t be saved to disk until you connect the file.

§ What's locked

The overall lifecycle of a game instance, start to finish.

  • Create Game → Configure Board → Place Properties → Invite Players → Start → Play → Elimination → Victory → Results → End.
  • ✓ Properties are placed at game setup, before play begins — each player places up to their max of 2 properties on blank interior tiles (locked in Sections 02 and 09). This answers "when can properties be placed" from the list below.

§ Resolved decisions

  • Can players change property placement after seeing opponents? No — final once placed, consistent with placement being locked in for the instance (Section 09).
  • Can players inspect the board before starting? No — not visible until the match actually begins.
  • When does the board become locked? Once all players have placed their properties and confirmed ready.
  • Can players join after starting? No — roster is fixed once the match starts.
  • Can eliminated players spectate? Yes — resolved in Section 18 (Multiplayer Rules).
  • When does the instance disappear? Scales with the match's stake tier — 48h/96h/1 week, resolved in Section 18 (Game Expiration).
