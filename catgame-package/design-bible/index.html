Recommended build order

Not to be tackled randomly — mechanics settle before any commercial or visual asset is produced.

  • Phase 00
    FoundationSketch the technical data model everything else will read and write.
  • Phase 01
    Core RulesTurn loop, board, characters, HP, victory condition.
  • Phase 02
    PvP SystemsTurn structure, the 20-card deck, equipment interaction.
  • Phase 03
    PropertiesPlacement, visits, card decks, leveling, economy.
  • Phase 04
    DungeonsUnlock rules, structure, rewards.
  • Phase 05
    Collection & MonetizationRarity, acquisition, trading, real-money purchases, anti-pay-to-win.
  • Phase 06
    Multiplayer & LifecycleElimination, player count, invites, disconnects, instance lifecycle, game modes.
  • Phase 07
    Asset SpecificationOnly now: card templates, art, board tiles, UI, VFX, audio.
