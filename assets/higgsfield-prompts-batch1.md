# Higgsfield prompts — Batch 1 (top-down board set + 3 class cats)

17 prompts, style anchor + projection tag already inlined. Generate, then save each to the
**exact path** in its heading. The prototype picks them up automatically.

**Suggested Higgsfield settings**

- Tiles, block facades, hazards: **1:1** aspect ratio. If the model supports a flat
  background colour, a soft grass green or plain white is fine — otherwise leave default.
- Characters: **1:1** or **3:4**, **transparent background** if available; if not, run the
  result through background removal before saving.
- Multi-tile blocks (Town Center, properties, special locations) must read as **one square
  image seen from directly overhead** — the prototype slices it across the block's tiles.
